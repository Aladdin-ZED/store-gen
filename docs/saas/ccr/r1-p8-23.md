# r1-p8-23: honest health sections (nullable frozen fields, a `sections` option) and two edge tally fields

- Status: **open, for the P8 merge** (P8 step 11). P8 builds against today's contract meanwhile.
- Filed by: P8 · Owners: maintainer (`src/lib/contracts/r1-p0.ts`, `src/lib/edge/proxy-log.ts`) · Spec: §H.5, PLA-§15.1,
  PLA-§15.2, PLA Q.25, SEC-16, §I.8 rule 3 ("null means not measured")
- Files: `src/lib/contracts/r1-p0.ts`, `src/lib/edge/proxy-log.ts` (and, after them, P8's `src/lib/platform/health.ts`)

## What

### 1. The frozen `PlatformHealth` cannot say "not measured"

P0 froze `PlatformHealth` with non-null sections, and `r1-p0.ts` asserts `Equals` on `edge`, `commerce`, `sheetsTop`,
`build`, `dataDir`, `db`, `tick`, `design` and `health`, and on `getHealth`'s one-argument signature. The step 11 brief
asks for a section that fails alone (null + `errors[section]`), `dataDir: null` before the first walk, and a cheap
`{ sections? }` subset for P1's `platform.alarms`.

What P8 did within the contract (no frozen field changed):

- `getHealthReport(ctx, { sections? }): Promise<HealthReport>` (new export): every section is `T | null`, failures are
  named in `sectionErrors`. This is the honest shape; P1's alarms and panels should read it.
- `getHealth(ctx)` = `toPlatformHealth(await getHealthReport(ctx))`: the frozen shape, plus three **additive** fields:
  `sectionErrors` (a failed section has empty values there and is named here; `dataDir` is `no_snapshot` before the
  first walk), `notMeasured` (placeholder numbers, e.g. `edge.foreignHosts24h`) and `detail` (handles, capacity, the
  boot-check verdict, error peaks, the build's commit and `gateMismatch`, …).

Requested change, at the P8 merge (P1 has not merged yet, so no consumer breaks):

```diff
@@ src/lib/contracts/r1-p0.ts  P8HealthAndExports
-  Assert<Equals<typeof platformHealth.getHealth, (ctx: PlatformCtx) => Promise<PlatformHealth>>>,
+  Assert<Equals<typeof platformHealth.getHealth, (ctx: PlatformCtx) => Promise<PlatformHealth>>>,
+  Assert<Equals<typeof platformHealth.getHealthReport, (ctx: PlatformCtx, opts?: { sections?: readonly platformHealth.HealthSection[] }) => Promise<platformHealth.HealthReport>>>,
```

and, if the maintainer prefers one shape, make the asserted sections `T | null` (then `getHealth` returns the report's
values directly and `sectionErrors` stays). Either way P1 codes against `getHealthReport` for "unavailable" states.

### 2. `edgeTally()` has no foreign-host count and no Worker version

`getHealth().edge.foreignHosts24h` and `workerVersion` (SEC-16: "the health panel could never read the Worker
version") have no source today: `edgeTally()` returns the bad-key counters and two times only, and `noteEdgeCheck` does
not see `EffectiveHost.workerVersion`. P8 reads both fields **when present** (`src/lib/jobs/edge-tally.ts`
`tallyForeignHosts`, `tallyWorkerVersion`), so nothing in P8 changes when this lands. Until then
`foreignHosts24h` is listed in `notMeasured` and `workerVersion` is null.

## Why

§I.8 rule 3 and the brief: null means not measured, 0 means measured zero. A console that shows "0 foreign hosts" or a
zeroed render queue when the read failed tells staff something false. PLA-§15.2's acceptance ("Edge panel on the
temporary domain reads S mode off with no network call") already holds: `edge` reads the in-process tally and the
error ring only.

## Effect on others

- P1 (console): read `getHealthReport` (or `sectionErrors` on `getHealth`) to render "unavailable" per panel.
- No frozen landing / runtime / order / PHP contract is touched.
