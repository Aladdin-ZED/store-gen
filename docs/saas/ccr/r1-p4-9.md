## 1. Export `isEditable` and `overlayOpen` (src/components/builder/shortcuts.ts:16-25)

Core §I.3 and OPE-§13.3 say the queue reuses the builder's two rules. They are module-private, so the console carries
a verbatim copy in `src/components/admin/queue/keys.ts`. Diff:

```diff
-function isEditable(target: EventTarget | null): boolean {
+export function isEditable(target: EventTarget | null): boolean {
-function overlayOpen(): boolean {
+export function overlayOpen(): boolean {
```

After the merge P4 replaces its copy with `export { isEditable, overlayOpen } from "@/components/builder/shortcuts";`
(or both move to a shared `src/components/admin/lib/keys.ts`; either is fine).

## 2. The `--info` / `--info-ink` tokens (core §I.6 rev 2, OPE Q.16)

Not in `globals.css` yet. The console reads `var(--info, oklch(0.55 0.13 250))` and `var(--info-ink, …)` (dark:
`oklch(0.74 0.1 250)` / `oklch(0.82 0.08 250)`), hue 250, so it picks the generator's values up with no change once
they ship. Same for `--dur-1/2/3` and `--ease-out` (fallbacks 120 / 180 / 240 ms and `cubic-bezier(.2,.8,.2,1)`).

## 3. The shell's key handler and the `?` sheet

`src/components/admin/shell/commands/ops.ts` now exports `shortcuts = { scope: "queue", path: "/queue", keys:
QUEUE_KEYS }`. When P2's chords and `?` sheet land:

- list `shortcuts.keys` in the `?` sheet while the path ends in `/queue` (the console also opens its own sheet on `?`);
- the shell's single key `C` (Create menu, mentioned in commands/ops.ts) must not fire on `/queue`, where `C` is Call;
  chords (`G …`) are disjoint from the queue map (`test:ops` [static · console]).

## 4. The shared pulse poller (core §I.4)

Not in the base. The console's counters and "My callbacks" come from `GET /ops/state?view=queue` (15 s while visible,
ETag / 304), which is one of the five endpoints the brief allows. When P2's `BroadcastChannel("sg-pulse:<storeId>")`
poller exists, the console can read `counts.dueCallbacks` from it and keep `/ops/state` for the list itself.

## 5. `error.<code>` aliases (extends r1-p4-6)

The console shows these P4 codes through `ops.error.<code>` (en / fr / ar): `bad_due`, `bad_duplicate`, `held`,
`not_callable`, `too_short`, `network`, `generic`. Add `error.<code>` aliases next to r1-p4-6's, or let the shell fall
back to `ops.error.<code>`.
