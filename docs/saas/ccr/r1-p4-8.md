## 1. `finance_lite` through `flagValue`

### What

`src/lib/finance/lite/flag.server.ts` (P4) reads the flag through an adapter: the declared default
(`src/lib/flags/defs/ops.ts`, `finance_lite`, release, `true`), overridden by the seeded `flags.default_value` when
the console changed it. P1's resolver (override user > store > plan > market → rules → default) is not in P4's base.
At the merge, replace the body with P1's function and keep the signature:

```ts
// src/lib/finance/lite/flag.server.ts
import { flagValue } from "@/lib/platform/flags";
export async function financeLiteOn(scope: StoreScope): Promise<boolean> {
  try {
    return (await flagValue<boolean>(FINANCE_LITE_FLAG, { storeId: scope.storeId })) === true;
  } catch {
    return flagDef(FINANCE_LITE_FLAG)?.default === true;
  }
}
```

### Why

OD25 / core D63: the maintainer can defer Profit lite by flipping the flag; per-store overrides need P1's order.
