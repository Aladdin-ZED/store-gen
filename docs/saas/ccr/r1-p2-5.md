## 2. P3 / P4: the Create menu (`C`, SF-01)

The Create page of ⌘K lists every `commandsFor(ctx)` entry whose `group` is `"create"`, in registry order, after
P2's `shell.create_page` (landing / both, `pages.write`) and `shell.invite` (`members.invite`). Nothing in P2 names
another track's command, so each entry appears at its merge:

| Entry | Owner, file | Fields `test:shell` assumes (fixture) |
|---|---|---|
| Create a campaign (SF-01) | P3, `src/components/admin/shell/commands/landing.ts` | `id: "landing.new_campaign"`, `group: "create"`, `permission: "campaigns.write"`, `mode: "landing"` |
| Manual order | P4, `src/components/admin/shell/commands/ops.ts` | `id: "ops.manual_order"`, `group: "create"`, `permission: "orders.create"` |
| Product (R2) | R2 | `release: "R2"`, `mode: "catalog"`: hidden by `commandsFor` in R1 |

A `HealthFix` of kind `action` runs the command with its `actionId` (PD66) through `commandForFix`
(`src/components/admin/shell/palette-logic.ts`): it must be a registered id the member may run, or the fix shows as a
link or not at all.

## 3. P3 / P4 / P5 / P7: navigation items and settings tabs

- **Settings tabs.** The settings sub-navigation is the registry's `settings` group (`settingsTabs`,
  `src/components/admin/shell/store-nav.ts`). P2's tabs use `order` 10 (General), 20 (Market), 80 (Security), 90
  (Address), 100 (Plan & usage), 110 (Audit), 120 (Danger zone). The others slot between Market and Security:
  Checkout & delivery 30 (P4), Policies 40 (P3), Brand 50 (P3), Anti-spam 60 (P5), AI 70 (P7). A tab gets its muted
  one-line description from the key `<its label key>_lead` when the track's catalog has one.
- **Interim items.** Until a track contributes its own item, `INTERIM_NAV` (`src/components/admin/shell/nav/t4.ts`)
  keeps today's screen visible: Orders (P4); Pages, Generate (P3); Sheets, Pixels, Anti-spam (P5); Local AI (P7).
  An interim item disappears as soon as a registry item has the same `id` or the same link, so the owner's item
  replaces it without a P2 edit. Keep the R1.0 ids (`orders`, `pages`, `generate`, `sheets`, `pixels`, `anti-spam`,
  `ai`) or the same link.
- **Icons.** The shell maps these registry icon names (lucide, no `Icon` suffix): Bell, ContactRound, Cpu, FileText,
  Gauge, Globe, Headset, History, Images, Inbox, LayoutGrid, Link, Link2, ListChecks, Megaphone, MessageCircle,
  Package, PackageOpen, Palette, PanelsTopLeft, PhoneCall, Radar, ReceiptText, ScrollText, Send, Settings2, Sheet,
  ShieldBan, ShieldCheck, SlidersHorizontal, Sparkles, Store, TriangleAlert, Truck, UsersRound, Wallet, Webhook. Any
  other name draws a circle. A track that needs another one asks P2 (one line in the map).
- **`G` chords.** `G O`, `G Q`, `G L`, `G C`, `G P` go to the item whose id is `orders`, `queue`, `leads`,
  `customers` or `pages` when the member sees it; with no such item the chord does nothing and the shortcut sheet
  leaves it out (the queue falls back to `/queue` for `agents.self` until P4's item exists).
