# r1-p7-1: spec sync for the price seed, the eval-gate refinements and `estimate()`'s arguments (ai.md AI-§M.5, AI-§B.2, AI-§C.2)

- Status: open
- Filed by: P7 · Owner of the file: maintainer (docs/saas/spec/ai.md has no R1 owner)
- Files: docs/saas/spec/ai.md (text only; no code file of another track changes)

## What

Three text edits in ai.md, so the spec matches what P7 step 1 built. No code change is requested.

1. **AI-§M.5, `prices`.** Replace

   ```ts
   prices: z.record(ModelId, PriceRow).default(SEED_PRICES),
   ```

   with

   ```ts
   prices: z.record(ModelId, PriceRow).default({}),   // confirmed rows only (console, probe); SEED_PRICES apply under them at read time (effectivePrices)
   ```

   and add one sentence under the AI-§B.2 seed table: "The seed rows are `SEED_PRICES` in
   `src/lib/settings/keys/platform_ai.ts`, merged under the stored rows by `effectivePrices(stored)`; `SEED_PRICE_NOTES`
   marks each seed cell that is derived from a published multiplier (`derived`) or that two sources disagree on
   (`verify`: Sonnet 5.5 cache reads, the higher $0.20 kept). A stored row replaces its seed row and its notes."

2. **AI-§M.5, `evalGate`.** After the `jury` comment, add: "the same refinement refuses `evalGate.judgeModel` equal to
   `classes.worker.model`, and `directorAutoDefault: true` while `preferenceTest` is null (QUAL-11)."

3. **AI-§C.2, `estimate`.** Replace

   ```ts
   export function estimate(task: AiTaskId, input: unknown, cls: TaskClass, opts: { batch: boolean; fast: boolean; stages?: number }): { micros: number; credits: number };
   ```

   with

   ```ts
   export function estimate(task: AiTaskId, input: unknown, opts: { batch: boolean; fast: boolean; stages?: number; model: string; prices: PriceTable; imageTokens?: number }): { micros: number; credits: number };   // src/lib/ai/quota/cost.ts (pure); model = classFor(task).model
   ```

## Why

1. P0 decided (p0-report §6, decision 2) that `platform_ai.prices` defaults to empty so that no stored default invents a
   price, and `src/lib/settings/selftest.ts` (maintainer) asserts `prices: {}`. Seeding the stored default, as AI-§M.5
   writes it, would break `test:settings`. Resolving the seed at read time keeps that decision and still prices every
   call with the AI-§B.2 rows from the first deploy. The seed rows were checked against the bundled Claude API reference
   (cached 2026-10-06): every figure matches AI-§B.2; the cells only a multiplier gives (Opus 5 and Opus 4.8 writes and
   batch, Sonnet 5.5 batch, Haiku 5.5 cache and batch) are marked `derived`.
2. AI-D28 says the judge is never the model under test; a single judge equal to the Worker model breaks it the same way
   a jury does. AI-§M.5 already says `directorAutoDefault` "may be set true only when ai_eval_runs has a passing
   preference run"; the schema now refuses the flag without the recorded run (the server action still checks the run).
3. `estimate` is pure: it needs the class model's price row, not the class name, so the caller passes the model and the
   table it resolved (`classFor` + `effectivePrices`).

## Effect on others

None. No other track reads `platform_ai.prices`, `evalGate` or `estimate`. `test:settings` stays green unchanged.
