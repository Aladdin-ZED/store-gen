### Facts the runbook relies on (verified, not assumed)

- **The build will succeed on Hostinger.** The build log of `01a16abd` shows Hostinger runs a plain `npm install` and
  installs the devDependencies: 828 packages, and the deprecation warnings for `eslint@9` and drizzle-kit's
  `@esbuild-kit/*`, which are devDependencies only. `tsx` (dev) is the one devDependency the new `prebuild` needs.
  Every other build-time package is a dependency: `typescript`, `esbuild`, `lightningcss`, `@tailwindcss/node`,
  `@tailwindcss/oxide`, `drizzle-orm`, `zod` and `next`.
- These files are unchanged since the live commit `3598537`: `package-lock.json`, `next.config.ts`, `.npmrc` and
  `tsconfig.json`. There is still no `postcss.config` and no `turbopack.rules`. The only new CSS input is
  `src/app/(marketing)/marketing.module.css`, a plain CSS module that Turbopack compiles natively without a worker.
  `next/font/local` is the same as before.
- **The gate SHA reaches the boot log.** Turbopack traces `qa/.gate-ok` (read by `src/lib/db/boot-config.ts`) into
  `.next/server/instrumentation.js.nft.json` when the file exists at build time. The archive always contains it, so the
  standalone output carries it, and the boot logs `gate passed on <sha>` (seen in the rehearsal).
- **What the live site does during the build.** Hostinger installs and builds in a separate folder. The old version
  keeps serving until `Switching "current" to the new version`, then `Restarting Node.js server` (0.3 s in
  `01a16abd`). A build that fails never reaches `==> Publishing`, so the previous version stays live. The env replace
  of step 2.3 restarts the **old** app (3598537) with the 16 keys, which is harmless: it ignores `PLATFORM_URL` and
  `DATA_DIR`, and `PUBLIC_URL` is unchanged. The new process runs migration 0004 in `register()` before it serves
  (about 3 s on XAMPP, far under the 120 s cap), then the one-time tasks in the background.
- **Runtime logs can be read.** `hosting_nodejs_runtime-logs` returns the app's console lines as entries with a level
  (`[boot] …`, `[upgrade-check] …`), so the boot can be checked without hPanel.

### Findings that do not block (recorded; none needs a change before this deploy)

1. **`DATA_DIR` in R1.0 is only checked as a path.** `src/lib/db/boot-config.ts` warns for a relative path, a path
   inside the app folder, a path under `public_html` or an unset value. Nothing in R1.0 writes to it, so there is no
   writability check and no `.sg-owner` marker yet. Those arrive with P8's storage check (§G.2): if the folder is not
   writable, it logs `[boot] ERROR media storage …`, uses the DB backend and shows a red health tile, and it never
   stops the app. In R1.0 the §H.10 "marker" item does not apply. The hand-made probe file (steps 2.1 and 5.2) is the

### 7.1 `sg-smoke.mjs`

```js
// R1.0 live smoke (docs/STORE-SAAS.md §H.10, docs/HANDOFF.md §4 step 8). Read-only except one cron tick and one
// refused empty order. Reads PLATFORM_URL, ADMIN_GATE and CRON_KEY from the env file; prints statuses, never a value.
//   node sg-smoke.mjs <env file> [--store <handle>] [--zip <uploaded archive name>]
import { readFileSync } from "node:fs";

const [file, ...rest] = process.argv.slice(2);
const opt = (n) => { const i = rest.indexOf(`--${n}`); return i >= 0 ? rest[i + 1] : null; };
const env = {};
for (const line of readFileSync(file, "utf8").split(/\r?\n/)) {
  const m = /^\s*([A-Z0-9_]+)\s*=(.*)$/.exec(line);
  if (m) env[m[1]] = m[2].trim().replace(/^(['"])(.*)\1$/, "$2");
}
const base = new URL(env.PLATFORM_URL);
const host = base.host;
let bad = 0;
const ok = (cond, label) => { console.log(`${cond ? "✓" : "✗"} ${label}`); if (!cond) bad++; };
const get = (path, init = {}) => fetch(new URL(path, base), { redirect: "manual", ...init });
const DROP = new Set(["date", "connection", "keep-alive", "transfer-encoding", "content-length", "server", "x-litespeed-cache", "alt-svc", "platform", "panel", "x-turbo-charged-by"]);
const headerSet = (r) => JSON.stringify([...r.headers].filter(([k]) => !DROP.has(k)).sort());
const F6 = { "x-content-type-options": "nosniff", "x-frame-options": "DENY", "referrer-policy": "no-referrer", "cross-origin-opener-policy": "same-origin", "cross-origin-resource-policy": "same-origin", "strict-transport-security": "max-age=63072000" };

// 1. health
const h = await get("/api/health");
const hj = await h.json().catch(() => ({}));
ok(h.status === 200 && hj.app === "store-gen" && hj.db === "ok", `/api/health 200, app store-gen, db ok (build ${hj.build ?? "?"})`);
ok(h.headers.get("cache-control") === "no-store", "/api/health Cache-Control no-store");
// 2. marketing home
const home = await get("/");
const homeHtml = await home.text();
ok(home.status === 200, `/ ${home.status} (marketing page)`);
ok(home.headers.get("cache-control") === "public, max-age=0, s-maxage=300", "/ indexable marketing cache policy");
ok(!home.headers.has("x-powered-by"), "/ no X-Powered-By");
// 3. the neutral 404 everywhere, one header set, the §F.6 headers
const paths = ["/admin", "/api/admin/x", "/d/x", "/no/such/deep/path", "/no-such-slug-qa", "/s/no-such-handle-qa"];
const r404 = [];
for (const p of paths) r404.push(await get(p));
ok(r404.every((r) => r.status === 404), `404 on ${paths.length} paths incl. /admin without the gate cookie (${r404.map((r) => r.status).join(" ")})`);
ok(new Set(r404.map(headerSet)).size === 1, "one 404 header set (proxy, routes, fallback rewrite)");
const bodies = await Promise.all(r404.map((r) => r.text()));
ok(new Set(bodies).size === 1, "one 404 body");
ok(Object.entries(F6).every(([k, v]) => r404[0].headers.get(k) === v), "404 carries nosniff, DENY, no-referrer, COOP/CORP same-origin, HSTS");
ok(/^default-src 'none'; style-src 'sha256-[^']+'; img-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'$/.test(r404[0].headers.get("content-security-policy") ?? ""), "404 hash CSP default-src 'none'");
const head = await get("/admin", { method: "HEAD" });
ok(head.status === 404, "HEAD /admin 404");
// 4. the console gate
const g = await get(`/${env.ADMIN_GATE}`);
const loc = g.headers.get("location") ?? "";
ok(g.status === 303 && new URL(loc, base).pathname === "/admin", `/<ADMIN_GATE> ${g.status} → ${new URL(loc || "/", base).pathname}`);
ok(new URL(loc || "/", base).host === host, "gate redirect stays on the platform host");
ok(g.headers.getSetCookie().some((c) => c.startsWith("__Host-csg=") && /;\s*secure/i.test(c) && /httponly/i.test(c)), "gate sets __Host-csg (Secure, HttpOnly)");
ok(g.headers.get("cache-control")?.includes("no-store") === true, "gate 303 private, no-store");
// 5. auth pages
for (const p of ["/login", "/signup"]) {
  const r = await get(p);
  ok(r.status === 200 && /'nonce-/.test(r.headers.get("content-security-policy") ?? "") && r.headers.get("referrer-policy") === "same-origin", `${p} 200, nonce CSP, same-origin`);
}
// 6. the order API refuses an empty order
const order = await get("/api/public/order", { method: "POST", headers: { "content-type": "application/json", origin: base.origin }, body: "{}" });
const orderText = await order.text();

// 7. cron, header form
const cron = await get("/api/cron/tick", { headers: { "x-cron-key": env.CRON_KEY } });
const cronText = await cron.text();
ok(cron.status === 200 && cronText.startsWith('{"ok":true'), `cron tick with X-Cron-Key → ${cron.status} {"ok":${cronText.startsWith('{"ok":true')}…}`);
const cronNoKey = await get("/api/cron/tick");
ok(cronNoKey.status === 404, "cron tick without the key → 404");
// 8. the store setup created
const handle = opt("store");
if (handle) {
  const s = await get(`/s/${handle}`);
  ok(s.status === 200, `/s/${handle} ${s.status} (its home page or the "no page yet" page)`);
}
// 9. the app folder is never served as files (the web server answers 403 for dotfiles, the app 404 for the rest);
// --zip <name>: the uploaded archive is gone after "Syncing public_html"
const files = ["/.env", "/package.json", "/server.js", "/qa/.gate-ok", "/drizzle/0004_tenancy.sql", "/.next/BUILD_ID"];
const zip = opt("zip");
if (zip) files.push(`/${zip}`);

for (const p of files) fileStatus.push((await get(p)).status);
ok(fileStatus.every((s) => s === 403 || s === 404), `app files not served: ${files.length} paths → ${fileStatus.join(" ")}`);
// 10. no client bundle carries the PLATFORM_URL value (ENGC-26)
const scripts = new Set();
for (const html of [homeHtml, await (await get("/login")).text(), await (await get("/signup")).text()]) {
  for (const m of html.matchAll(/(?:src|href)="([^"]*\/_next\/static\/[^"]+\.js)"/g)) scripts.add(m[1]);
}
let hits = 0;
for (const s of scripts) if ((await (await get(s)).text()).includes(host)) hits++;
ok(scripts.size > 0 && hits === 0, `client bundles: ${scripts.size} scripts, ${hits} contain the PLATFORM_URL host`);

console.log(bad ? `✗ smoke FAILED: ${bad} check(s)` : "✓ smoke passed");
process.exit(bad ? 1 : 0);
```
