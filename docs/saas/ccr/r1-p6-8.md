## 1. `allowedNumbers` is private in `src/lib/ai/guard.ts` (P7)

DES-§9.11 makes `allowedNumbers` (`src/lib/ai/guard.ts:52-66`) the one source of "merchant numbers", shared by the
`{number}` slot of the generator (DES-§9.12), specificity (DES-§9.6) and `numbersReport` (D1). The function is not
exported, so P6 cannot call it.

**Today (P6 code, no shared file touched):** `merchantNumbers(facts)` in `src/lib/design/cliche.ts` mirrors it line
for line (the facts, the product name, the price and the delivery line; each number added as typed and as
`String(Number(n))`, Arabic-Indic and Eastern digits read as ASCII). The mirror goes when the export lands.

**Ask (P7):** export it, signature unchanged.

## 2. The store purge deletes `headline_shingles` by owner tag (core §F.9)

§F.9 lists `headline_shingles` "(by `owner_tag`)" in the purge order. The table has no `store_id`, so the purge
job's schema-driven `WHERE store_id = ?` pass does not reach it.

**Today (P6 code):** `purgeHeadlineShingles(scope: WriteScope)` in `src/lib/design/headlines.server.ts` deletes every
row of `ownerTagFor(scope.storeId)` (= `hmac(storeId, "shingle-owner")[:16]`, D35), in every niche.
`test:design-db` checks it leaves 0 rows for the tag, and the design tenancy case checks it leaves another store's
rows.

**Ask (core / P8, the purge job):** call it once, after the tenant tables, in the purge's design step:

```ts
import { purgeHeadlineShingles } from "@/lib/design/headlines.server";
// … after design_genomes
await purgeHeadlineShingles(scope); // headline_shingles by owner_tag (§F.9, DES-§2.2)
```
