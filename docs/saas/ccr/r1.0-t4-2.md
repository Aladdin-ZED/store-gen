## Why

- SHT-02 / SHT-04: the store-less `syncPendingOrders(opts)` kept for today's caller pushes **store #1's** queue only
  (never another store's orders into store #1's sheet, but every other store then waits for the cron tick).
- PIX-03: the store-less `enforceLibraryRule(tracking, userId)` runs against store #1's library and store #1's
  membership, which is right for the legacy panel and wrong for any other store's publish.
- `invalidatePixelUsage()` without a store clears every store's cached usage index; with the id only the publishing
  store's.
