## Lint decisions (C0b)

1. **L2 is strict.** Only `inStore` / `whereStore` / `byId` / `storeSql` on a scope parameter count as a store
   predicate. `eq(T.storeId, scope.storeId)` alone is reported as L2 but is not L2b.
2. **L4 skips frozen lookup tables.** A module-scope `Map` / `Set` that the type checker shows never changes needs no
   allow entry: it is created in a `ReadonlySet` / `ReadonlyMap` slot, or every reference to it in any file only reads
   it. A literal reading of §F.1 would list about 70 constant lookup sets in the allow file. Each new constant set of
   any track would then need a maintainer CCR.
3. **L4 skips the standalone `src/**/selftest*.ts` scripts.** The app never imports them. Every other rule still
   applies to them.
4. **The 32 allow entries** are the §E.6 rows marked "unchanged" or "platform guard", the five C0a globals
   (`__sgLockPool`, `__sgStoreInvalidators`, `__sgIdentity`, `__sgPrePublish`, `__sgNotifyStubWarned`) plus the
   registry `__sgCaches`, and the pure memo caches (colour maths, Intl formatters, market tables). Each entry has a
   reason. None is store data.
5. **Pins.** The pins at rev 2 are `src/lib/design/**` + `src/lib/jobs/tracks/design.ts` at 3 (DES-R9) and
   `src/lib/health/**` at 1. `src/lib/platform/**` and `src/lib/ai/platform/**` are at 0 until the P1 / P7 merges. The
   other allowlisted directories (`jobs`, `tenancy`, `auth`, `db`) are at today's count, 0. A T1 / T2 merge that adds
   annotations shows a PIN line. The maintainer re-pins at the R1.0 integration, as the approving reviewer.
6. **`mintScope()` outside the four seam files is L6**, as C0a's seam comment says. So is a type guard that narrows to
   `WriteScope`.

## Open item for the maintainer

- **`src/lib/media/store.ts` has no R1.0 owner.** T4 owns `src/lib/media/**` except `store.ts`, and P8 takes `store.ts`
  in R1 product. Its raw SQL looks up `media_files` by media key without `store_id` (L10 ×3).
  - `src/lib/media/` is not an annotation directory.
  - §E.3 rule 6 puts lookups by a random global key ("media key") in `src/lib/tenancy/public.ts`.
  - For R1.0 to exit at 0 violations, one of two things must happen. `store.ts` gets an R1.0 owner who adds the store
    predicate. Or the media-key resolver moves behind `public.ts` with `// tenancy: public-key media`.

## Known limits (by design, documented in the script)

- **L12 and L13 follow calls the checker can resolve statically.** That covers direct calls, callbacks passed by name,
  and nested arrow functions. A function picked at run time from a table or a dynamic `import()` is not followed.
- **Relational queries (`db.query.<table>.findFirst / findMany`) are covered by L1 and L2.** No code uses them today.
  The `where` option must be the SQL itself: the callback form of `where` cannot be checked, so the lint reports it.
- **Module-scope `let` caches** that are not a `Map`, a `Set` or a global are outside L4, as §F.1 words it.
