## Exact change

1. `src/landing/context.ts`:
   ```ts
   export interface StoreInfo { …; logo?: AssetRef; mark?: AssetRef; … }
   // StoreContext (src/landing/types.ts): mark?: ResolvedAsset | null
   // storeContext(): …, logo: info.logo ? assets.resolve(info.logo) : null, mark: info.mark ? assets.resolve(info.mark) : null,
   ```
   `src/lib/render/store-context.server.ts` and `src/lib/export/server.ts`: `...(brand.logo.mark ? { mark: { id: brand.logo.mark, alt: store.name } } : {})`.
   Then drop the cast in `favicon.ts` (`(ctx.store as { mark?: … }).mark` → `ctx.store.mark`). The exported pages
   bundle the mark's 64 px rendition through the export resolver's `url()` (it records the used keys).
2. Either `t4.ts`: `permission: "ai.use"` on the `generate` item (the route itself requires both, src/app/app/[store]/generate/page.tsx),
   or the array form in `types.ts` / `index.ts` (`[].concat(item.permission).every(ctx.can)`).
3. `store-nav.ts`: `Palette: PaletteIcon` in `ICONS` (import from lucide-react).
4. At the P7 merge: `saveVoice` → `updateStoreAiVoice(scope, actor, patch)` (P7's server function behind
   `updateStoreAiAction`); the audit line stays.
