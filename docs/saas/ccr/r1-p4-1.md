# r1-p4-1: `hooks.ts` imports `OrderActor` from the pure `state.ts`

- Status: applied at the P4 merge (main): `hooks.ts` takes `OrderActor` from `state.ts`.
- Filed by: P4 CALL CENTER · Owner of the file: maintainer (core §K.3)
- Files: src/lib/orders/hooks.ts

## What

P4 step 1 moved the `OrderActor` interface, unchanged, from `src/lib/orders/transition.ts` (server-only) to the pure
`src/lib/orders/state.ts`, beside `Move`, `OrderSnapshot` and `TransitionSource` (the OPE-§3.5 / §3.6 shapes the order
hooks receive). `transition.ts` re-exports it (`export type { OrderActor } from "./state"`), so every current import
compiles and `src/lib/contracts/r1-p0.ts` (`P4Transition`, `P4StateMachine`) still asserts the same shape. The hook
registry can now take all four order-state types from one pure module:

```diff
-import type { Move, OrderSnapshot, TransitionSource } from "./state";
-import type { OrderActor } from "./transition";
+import type { Move, OrderActor, OrderSnapshot, TransitionSource } from "./state";
 ...
-export type { Move, OrderSnapshot, TransitionSource } from "./state";
-export type { OrderActor } from "./transition";
+export type { Move, OrderActor, OrderSnapshot, TransitionSource } from "./state";
```

## Why

- `planTransition` (pure, isomorphic, OPE-§3.2) reads the actor's move classes (`movePermsOf(actor, source)`), so the
  type belongs with the plan; the drawer's "Move to…" menu (a client component, OPE-§12.6) builds `legalMoves` from it
  and must not import a `server-only` module, even for types.
- One source for the hook event types (OPE-§3.6) instead of two files.

## Effect on others

- None: a type-only import path. No frozen contract changes (the `OrderActor` shape is identical, asserted by
  `r1-p0.ts`). Until it is applied, the re-export in `transition.ts` keeps `hooks.ts` compiling.
- Additive on `Move` (recorded here for the P4 report): an optional `auto?: true` flag marks an automatic side move of
  the same write (OPE-§3.2), recorded as its own `state_changed` event with source `system`. Hooks that ignore it see
  the same moves as before.
