## 5. Tenancy lint L6 `platform-scope`: let `aiStoreSummary` mint its read scope (scripts/qa/tenancy-lint.ts, shared)

The frozen stub is `aiStoreSummary(ctx: PlatformCtx, storeId)` (src/lib/contracts/r1-p0.ts), and the brief puts its body
in `src/lib/ai/platform/**`. Its one read scope comes from `platformScope(ctx, storeId)` in
`src/lib/ai/platform/summary.ts` `storeSummary` (read-only: `getStoreSetting`, `usageValue`, the store's own runs and
jobs through `whereStore`; no write, no `platformRevealScope`). The L6 path rule allows the call only under
`src/app/admin/**` and `src/lib/platform/**`, so the lint reports **1 L6** (`platform-scope`) on that line until this
applies.

```diff
-    } else if (ref.file === F.platformSeam && ref.name === "platformScope" && !f.startsWith("src/app/admin/") && !f.startsWith("src/lib/platform/"))
+    } else if (ref.file === F.platformSeam && ref.name === "platformScope" && !f.startsWith("src/app/admin/") && !f.startsWith("src/lib/platform/") && f !== "src/lib/ai/platform/summary.ts")
```

(and the rule's message: "outside src/app/admin/**, src/lib/platform/** and the AI store summary"). The alternative, a
`platformScope` call in the profile page handing a `StoreScope` in, would change the frozen signature, so P7 does not
take it.
