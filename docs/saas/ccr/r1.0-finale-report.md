## 4. The gated archive (§H.10)

- Core §K.3 now lists `scripts/qa/gate-ok.ts` and this report as maintainer files (`test:ownership` needs an owner for
  every new file).
- `scripts/qa/gate-ok.ts` (new, the tail of `npm run gate`, maintainer-owned per §K.3): writes `qa/.gate-ok` =
  `{ "sha": <HEAD>, "at": <ISO> }`; refuses (exit 1, removes an older file) when the tree has changes other than
  `docs/saas/PROGRESS.md`.
- `scripts/deploy/archive.mjs <out.zip>` (new): refuses unless `qa/.gate-ok` exists, names the current
  `git rev-parse HEAD` and is younger than 24 h (5 min clock skew allowed), the tree is clean except
  `docs/saas/PROGRESS.md`, no tracked file looks like a secret (`.env*` but `.env.example`, `*.pem`) and the output is
  outside the repo or git-ignored. Then `git archive --format=zip HEAD` plus `qa/.gate-ok` (so the boot log names the
  gate commit), a self-check of the zip's central directory (every tracked file and only those, `package.json` at the
  root, no secret-like name) and it prints the path, commit, gate age, file count, size and sha256. No upload, no env
  file read.
