# r1-p1-2: the orders selftest follows PLA-§7.2's masked phone format

- Status: open (P1 keeps C0a's format live meanwhile: `PHONE_FORMAT = "c0a"` in `src/lib/platform/mask.ts`)
- Filed by: P1 CONSOLE (R1 step 1, `p1-core-pure`) · Owner of the file: maintainer (`src/lib/orders/selftest.ts` is
  T4's R1.0 file and has no R1 owner; `ownership-check --owner` answers "read-only in this phase")
- Files: `src/lib/orders/selftest.ts` (three expectations), `src/lib/platform/mask.ts` (one constant, P1's)

## Why

PLA-§7.2 fixes the masked phone as `"+212612345634" → "+212 6•• ••• •34"` (the country calling code, the first
national digit and the last two digits, grouped in threes). C0a's body, still live, answers `"+2126 ••••••34"`. P1's
step 1 wrote the PLA-§7.2 format (`maskPhoneGrouped`, tested in `test:platform` on Moroccan, French, NANP, UAE,
Russian and national numbers), but `test:orders` pins C0a's string on three lines of section 7 ("customer fields per
scope"), so switching `maskPhone` alone turns `npm test` red (3 failures, measured on this branch). The masking itself
is not in question: both formats hide the middle digits, and section 7's canary checks pass with either.

## What (one commit, at the P1 merge or before)

1. `src/lib/orders/selftest.ts`, section 7:

   ```diff
   -    phone: "+2126 ••••••34",
   +    phone: "+212 6•• ••• •34",
   …
   -  eq("mask: a partial row keeps its shape (blocklist phone)", maskCustomer(scopeOf("impersonation"), { phone: "+212612345634" }), { phone: "+2126 ••••••34" });
   +  eq("mask: a partial row keeps its shape (blocklist phone)", maskCustomer(scopeOf("impersonation"), { phone: "+212612345634" }), { phone: "+212 6•• ••• •34" });
   …
   -  eq("mask: the typed phone is masked like the phone", maskCustomer(scopeOf("impersonation"), { phone: "+212612345634", phoneRaw: "0612345634" }), { phone: "+2126 ••••••34", phoneRaw: "+2126 ••••••34" });
   +  eq("mask: the typed phone is masked like the phone", maskCustomer(scopeOf("impersonation"), { phone: "+212612345634", phoneRaw: "0612345634" }), { phone: "+212 6•• ••• •34", phoneRaw: "+212 6•• ••• •34" });
   ```

2. `src/lib/platform/mask.ts` (P1's file; listed here so both land together):

   ```diff
   -export const PHONE_FORMAT: "c0a" | "grouped" = "c0a";
   +export const PHONE_FORMAT: "c0a" | "grouped" = "grouped";
   ```

   P1 then deletes `maskPhoneC0a` and the switch in a later step; `maskPhone`'s frozen signature
   (`(e164: string) => Masked`, `src/lib/contracts/r1-p0.ts`) does not change.

## Proof

`npm run test:orders` (138 passed) and `npm run test:platform` (its `maskPhone follows PHONE_FORMAT` lines check the
live format against the grouped table once the constant is flipped) both green; `test:tenancy`'s masked canary cases
are format-independent (they look for the canary digits, which neither format shows).
