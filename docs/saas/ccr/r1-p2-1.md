## Why

Core D60 and §I.6 (rev 3, UX-38), DES-§16.6, §16.8 and §16.15, PLA-§22.18 rows 4 and 7: no spring, no overshoot curve,
nothing slower than 400 ms outside the builder canvas, no aurora, mesh or grain anywhere in the admin, logical

deleted the `.adm-aurora` / `.adm-grain` CSS and `--adm-grain` from `src/components/admin/styles/admin.css` (P2's since
P0b): the class names left below are now inert, and only their removal is asked for.

## The fix, per rule

| Rule | Replace with |
|---|---|
| `spring` (`type: "spring"`, a `SPRING` preset) | `{ type: "tween", duration: 0.18, ease: [0.2, 0.8, 0.2, 1] }` (≤ 0.18 for presses and pills, ≤ 0.24 for drawers and sheets) |
| `duration` (> 400 ms) | `duration-200` / `-300` (hover zooms, colour), `duration-400` at most for a one-off draw or number roll; motion `duration` ≤ 0.24. A looping shimmer becomes a static tint (DES-§16.8) |
| `overshoot` (`cubic-bezier(.34,1.36,.64,1)`) | `ease-[cubic-bezier(.2,.8,.2,1)]` or the `--ease-out` token |
| `aurora` (`adm-aurora`, `adm-grain`, the builder's "Film grain" option) | delete the classes; a hero keeps a flat surface (`bg-card` / `bg-muted/40`) |
| `physical-class` | `text-left` → `text-start`, `left-0` → `start-0`, `right-0` → `end-0`, `-right-16` → `-end-16`, `rounded-tl-*` → `rounded-ss-*`, `rounded-tr-*` → `rounded-se-*`, `rounded-bl-*` → `rounded-es-*`, `rounded-br-*` → `rounded-ee-*`, `border-l-2` → `border-s-2`, `border-r-2` → `border-e-2` |
| `dir-icon` | add `className="rtl:rotate-180"` (or `rtl:-scale-x-100` when the icon also rotates, e.g. a disclosure chevron) |
