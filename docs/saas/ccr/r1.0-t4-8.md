# r1.0-t4-8: the tenant navigation registry imports T4's dashboard items

- Status: applied in 7ffbc8c: `NAV_CONTRIBUTIONS = [...t4Nav]`, the types note dropped, and the `nav.*` /
  `nav.group.*` labels added to the admin catalogs in en, fr and ar (the shell still asks for "en" until P2 passes the
  viewer's locale).
- Filed by: T4 · Owner of the files: maintainer
- Files: src/components/admin/shell/nav/index.ts, src/components/admin/shell/nav/types.ts, src/lib/i18n/admin/en.ts

## What

1. `src/components/admin/shell/nav/index.ts`: import the R1.0 items of the dashboard move (`./t4.ts`, T4's extension
   file, §K.3) into the registry:

   ```diff
   +import { nav as t4Nav } from "./t4";
   …
   -export const NAV_CONTRIBUTIONS: readonly NavContribution[] = [];
   +export const NAV_CONTRIBUTIONS: readonly NavContribution[] = [...t4Nav];
   ```

2. `src/components/admin/shell/nav/types.ts`: drop the note about the single-tenant `../nav.ts` beside the folder.
   T4 removed that file: the shell's view of the registry is `../store-nav.ts` (labels, icons, the settings tabs).

3. Optional, `src/lib/i18n/admin/en.ts`: the English labels of the keys `nav.overview`, `nav.orders`, `nav.pages`,
   `nav.generate`, `nav.media`, `nav.history`, `nav.exports`, `nav.team`, `nav.sheets`, `nav.pixels`,
   `nav.settings` and `nav.group.*` (the values of `NAV_FALLBACK_LABELS` in `./t4.ts`), or a registered
   `en/<track>.ts` file for them at P0.

## Why

§I.3: the sidebar, ⌘K and the breadcrumbs read `navFor(ctx)`. The dashboard moved to `/app/<handle>` (§I.1) and its
items live in `nav/t4.ts` as `NavContribution`s with message keys. Until the registry imports them, the shell
(`store-nav.ts`) merges them in by id, so they show exactly once before and after this change. Until the catalogs
carry the keys, `shellLabel()` shows `NAV_FALLBACK_LABELS`, never a raw key.

## Effect on others

- None on frozen contracts.
- P2 (shell, R1 product) takes the items over; the merge-by-id in `store-nav.ts` keeps working with any later
  contribution that reuses an id.
