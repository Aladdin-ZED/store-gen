## Why

§G.2 / §H.4: the `DATA_DIR` boot check (owner marker, probe; ENGC-14) must run before serving, and pool-wait sampling
(ENGC-12, `getHealth().db.poolWaitP95Ms`, the `pool_wait` alarm) should start with the process.

## Meanwhile

`mediaBackend()` runs the check once, lazily and memoised, on its first call (P8 step 2): until the verdict exists it
answers the db backend, and `mediaBackendReady()` (the upload path, P8 step 6) awaits the verdict. The media disk cache
also awaits it before choosing `DATA_DIR/cache/media`. `runTick()` and `getHealth()` call `ensureOpsSamplers()` (P8
steps 3 and 11), so the samples start with the first tick instead of at boot.
